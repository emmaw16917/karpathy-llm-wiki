# Status Blocks

A Status block marks a claim that no longer stands as written. Keep the original claim, place the block directly beneath it, and never delete or silently rewrite the old text.

Use the block in any article type: source articles, overviews, and concept pages.

## Outdated

Use when a newer source supersedes the claim. The date is when the newer source was published or ingested.

> **Status: Outdated** (YYYY-MM-DD)
> {What changed and what the current understanding is, with source attribution.}

## Disputed

Use when sources disagree and neither has clearly superseded the other.

> **Status: Disputed**
> {The competing claims, each with source attribution.}

## Grounding

Every fact inside a Status block is subject to the Raw rule: link every raw file that holds it. When the conflicting content lives in another article, mark both articles and cross-link them. Lint reports malformed blocks: Outdated missing its date, or either block missing its explanation.
